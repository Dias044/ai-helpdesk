# AI HelpDesk — версия 1.1 (СРО4)
Интеллектуальная система обработки обращений студентов: классификация обращений, приоритет, семантический поиск по базе знаний, автоответ, очередь оператора, панель администратора.

## Запуск
1. Python 3.10+ и `pip install scikit-learn numpy` (matplotlib нужен только для train.py)
2. `python server.py 8000`, затем открыть http://localhost:8000 (при первом запуске создаётся helpdesk.db и 40 демо-обращений; если модель создана другой версией scikit-learn, она переобучается автоматически, менее 1 с)
3. Демо-аккаунты: student@turan.edu.kz / student123; operator@turan.edu.kz / operator123; admin@turan.edu.kz / admin123

## Тестирование (СРО4)
| Команда | Что делает |
|---|---|
| `python tests/test_api.py` | 19 регрессионных тестов API из СРО3 |
| `python tests/test_sro4.py` | 26 тестовых сценариев СРО4 (некорректные данные, бизнес-правила, новые функции) |
| `python evaluate.py` | оценка ИИ на наборах manual / расширенном / контрольном, отказ вне тематики, опечатки |
| `python loadtest.py` | нагрузочный тест: 1, 10, 25, 50 параллельных клиентов |
| `python bench_queue.py 3000` | время загрузки очереди оператора при 3000 обращениях |
| `python tune_priority.py` | подбор весов формулы приоритета |
| `python train.py` | обучение, сравнение моделей, model/metrics.json, model/confusion.png |
| `python feedback_report.py helpdesk.db` | сводка пользовательского тестирования (SUS, оценки ответов) → feedback_report.csv |

## Изменения версии 1.1
- ИИ: словарь нормализации (англ./каз./транслит), класс «вне тематики», новые обучающие формулировки, формула приоритета с признаком сбоя P и подобранными весами, проверка версии модели, учёт отключённых категорий, подсказки оператору.
- Сервер: проверка входных данных (400 вместо 500), ограничение размеров, защита от подбора пароля (429), запрет сообщений в решённые обращения и повторной эскалации, очередь с JOIN и пагинацией, очередь соединений 128, журнал ошибок сервера.
- Интерфейс: адаптивная вёрстка, всплывающие сообщения об ошибках, уведомление о передаче оператору, оценка полезности ответа, анкета SUS, страница «Обратная связь», подсказки из базы знаний для оператора, счётчик символов.

Переменные окружения: HELPDESK_DB, HELPDESK_SECRET. Данные для обучения синтетические, база знаний демонстрационная.
